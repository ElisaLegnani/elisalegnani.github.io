# My website

The repository for my personal website, a small site where I experiment with design and web development. See the live version at [elisalegnani.github.io](https://elisalegnani.github.io/).

## About

This repo contains the code, styles, and content behind the site, built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages. I wrote a [blog post](https://elisalegnani.github.io/website/2026/02/27/new-website.html) about how I got started.

Feel free to explore and reuse parts of it (SASS, layouts, etc.) for your own work.

## Contributing

This is mainly a personal project, but suggestions are welcome. Feel free to open an issue or submit a pull request.
